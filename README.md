## Sobre o projeto

O **Evena** é uma plataforma digital desenvolvida para facilitar a descoberta, a divulgação e o gerenciamento de eventos no Brasil.

A aplicação busca aproximar pessoas de experiências culturais, sociais e de entretenimento, reunindo informações sobre eventos em um ambiente de fácil acesso e navegação.

Por meio da plataforma, os usuários podem explorar eventos, consultar suas informações e salvar aqueles que despertam seu interesse. Já os organizadores contam com recursos para cadastrar e gerenciar seus próprios eventos.

O Evena foi desenvolvido como Trabalho de Conclusão de Curso (TCC).

## Objetivos

O principal objetivo do projeto é desenvolver uma solução que simplifique a busca por eventos e amplie as possibilidades de divulgação para organizadores.

A proposta é oferecer uma experiência que atenda tanto ao público interessado em descobrir novas atividades quanto às pessoas e empresas responsáveis pela organização de eventos.

## Funcionalidades

### Área do usuário

- Exploração de eventos disponíveis na plataforma.
- Pesquisa e utilização de filtros para encontrar eventos.
- Visualização das informações e dos detalhes de cada evento.
- Cadastro e autenticação de contas.
- Visualização e edição do perfil.
- Salvamento e gerenciamento de eventos favoritos.

### Área do organizador

- Cadastro e autenticação de organizadores.
- Criação e gerenciamento do perfil da empresa.
- Cadastro de eventos por etapas.
- Edição e gerenciamento das informações dos eventos.

## Tecnologias utilizadas

O desenvolvimento do Evena envolve tecnologias voltadas à construção de interfaces web, desenvolvimento de APIs e gerenciamento de dados.

### Frontend

- **Angular:** framework utilizado na construção da aplicação.
- **TypeScript:** linguagem utilizada no desenvolvimento da lógica da interface.
- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e responsividade.

### Backend

- **Java 17:** linguagem utilizada no desenvolvimento da API.
- **Spring Boot:** framework responsável pela estruturação dos serviços.
- **Spring Data JPA:** gerenciamento da persistência de dados.
- **Hibernate:** mapeamento objeto-relacional.

### Banco de dados e infraestrutura

- **H2:** banco de dados utilizado na configuração local da API.
- **SQL Server:** banco de dados definido na configuração de ambiente Azure.
- **Microsoft Azure:** plataforma de infraestrutura e hospedagem.

## Arquitetura

O Evena possui uma arquitetura dividida em duas aplicações principais, responsáveis por diferentes partes do funcionamento da plataforma.

**Frontend**

Desenvolvido em Angular, é responsável pela interface visual, navegação, interação com os usuários e comunicação com os serviços do backend.

**Backend**

Desenvolvido em Java com Spring Boot, disponibiliza uma API REST responsável pelo processamento das requisições, aplicação das regras de negócio e gerenciamento dos dados.

As duas aplicações se comunicam por meio de requisições HTTP, permitindo a integração entre a interface e os serviços da plataforma.
